# Tend Lite

The companion app for the free course
**[Tend Engineering](https://ikode-agbi.github.io/tend-engineering-course/)**.

Tend Lite is a tiny couples app, built one piece each weekend over the course's eight weeks:
sign-up, pairing with an invite code, and a daily question where your partner's answer stays
hidden until you've both answered.

This repository is the course author's own build, added week by week alongside the course.
Build yours first, then compare. There's more than one right answer.
